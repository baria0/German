# Resources

Few resources, used every day, beat a long list you never open. Start with the **core stack**. Add extras only when the core feels easy.

Level tags: 🟢 A2 · 🟡 B1 · 🔴 B2+

## ⭐ Core stack (daily)

| # | Resource | Level | Why | How to use it |
|---|---|---|---|---|
| 1 | **Daily session with Claude** (this repo) | all | Speaking output with instant correction, mistake tracking | 30 to 40 min, use voice dictation in German |
| 2 | [**Easy German**](https://www.youtube.com/@EasyGerman) (YouTube) | 🟢 🟡 🔴 | Real street German, natives speaking naturally, German and English subtitles | Start with the *Super Easy German* series. Watch once with German + English subtitles, then again with German only. Shadow 1 minute (pause, repeat out loud). |
| 3 | [**DW Learn German: Nicos Weg**](https://learngerman.dw.com) | 🟢 then 🟡 | Free structured course in video episodes (A1 to B1), exercises, everyday situations | Do A2 now (fast, as revision), then B1. One episode per day, do the speaking exercises out loud. |
| 4 | [**Anki**](https://apps.ankiweb.net) + [`vocab/chunks.tsv`](vocab/chunks.tsv) | all | Spaced repetition: you only review what you are about to forget | 10 min daily. Import the TSV (see below). Say each card **out loud**. |
| 5 | **Real conversation** (see Darmstadt section) | all | The final test: speaking with real people in real time | At least once a week a real conversation, daily mini moments in shops |

## 🗣️ Speaking partners

| Resource | Notes |
|---|---|
| [Tandem](https://www.tandem.net) | Language exchange app. Stronger for moderated 1:1 video calls. Offer Turkish or English, ask for German. |
| [HelloTalk](https://www.hellotalk.com) | Bigger community, good for **voice messages** (less stress than live calls). |
| Easy German membership (optional, paid) | Transcripts and extra content, if you want to support them. |

**Tandem rule:** split time 50/50, and agree that the partner corrects you. Prepare 3 questions before each call.

## How to import the deck into Anki

1. Download [`vocab/chunks.tsv`](vocab/chunks.tsv) (button "Raw", then save the page).
2. Anki desktop: **File > Import**, choose the file. The first line tells Anki the column names.
3. Map: German to *Front*, English to *Back*, Note to an extra field (or Back), Tags to *Tags*.
4. Turn on "Basic (and reversed card)" if you want cards in both directions (recommended: English to German trains speaking).
5. When the file gets new phrases, import again: Anki updates existing cards and adds the new ones (choose "update existing notes" when the first field matches).
